## Bugs found in review (mapped to roadmap tasks)

1. **HERMES_HOME double-scope** — `index.ts` sets `defaultHermesHome=activeHermesHome=$HERMES_HOME`; `handlers.ts` appends `/profiles/<name>`, giving `.../profiles/anikke/profiles/anikke` when env is already profile-scoped. (Task 1.1)
2. **Cowork composer no-op** — `CoworkPage` reuses chat `Composer` reading `useChatStore.sessionId` (null in Cowork). Steering dead. (Task 3.2)
3. **Plan/approval renderer-only** — `approvalMode` never sent to main; `upsertPlanTask`/`setParent` never called; PlanTab always empty. (Task 3.3/3.4)
4. **Kanban WS unscoped** — pump broadcasts all events; `KanbanWsSubscribe` is a stub. (Task 3.4)
5. **Artifact detection dead** — store matches `msg.name==='write_file'|'patch'`, translator sets `name` from `update.title`. (Task 3.5)
6. **ACP crash silent** — translator drops `exit`/`error`; bridge only handles `kind==='message'`. (Task 4.4)
7. **Dashboard child leaks on quit** — `before-quit` never kills spawned `hermes dashboard`; fixed port 9119 no fallback. (Task 1.4)
8. **No project layer / no cwd validation / no security-model.md** (Task 0.3, Phase 2)
9. **No task persistence** — `cowork.store` in-memory; `startTask` wipes state; no resume. (Task 3.1)

## Cowork slice (2026-09-01, `9e06bb2`)
Discovered the old Cowork design doesn't match Hermes 0.20.6: agent ignores `kanban_create` prompts, no ACP `plan` updates, kanban events WS needs an unminted auth ticket (`POST /api/auth/ws-ticket`).
- Rebuilt: kickoff asks for a numbered plan + STOP (verified); PlanTab parses steps from the transcript and shows an Approve gate.
- Approval mode enforced via ACP `session/set_mode` (`default`/`accept_edits`) — verified on 0.20.6. `session/cancel` does NOT exist on 0.20.6.
- Cowork sessions run isolated (own ACP child) so Stop hard-kills; chat stays pooled.
- Artifact detection now on tool-call `kind` (edit/delete/move) + path arg.
- KanbanWsPump not started (note in index.ts).
